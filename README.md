# Manajemen Data Laptop

**NPM:** 2428240033  
**Mata kuliah:** PAW2 — Kuis 1

Aplikasi sederhana untuk mengelola data laptop dengan tiga field:

| Field | Tipe | Keterangan |
|---|---|---|
| `merk_laptop` | String | Merek laptop |
| `processor` | String | Jenis atau model processor |
| `harga` | Number | Harga laptop dalam rupiah |

## Contoh data

```json
{
  "merk_laptop": "ASUS",
  "processor": "Intel Core i5",
  "harga": 8500000
}
```

## Menjalankan aplikasi

Buka file `index.html` di browser. Data contoh dapat ditambah, diedit, dan dihapus dari tabel. Data disimpan di penyimpanan lokal browser (localStorage).
